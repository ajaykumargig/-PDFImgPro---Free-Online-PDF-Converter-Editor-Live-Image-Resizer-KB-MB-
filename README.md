# 🚀 PDFImgPro.app - Universal PDF & Live Image Studio

**PDFImgPro** is a fast, free, and 100% private browser-based tool to edit PDFs, resize images to exact dimensions with live calculation, compress photos to target KB/MB sizes, and convert file formats online.

---

## 🌟 Key Features

### 📄 PDF Utilities
- **Merge PDF:** Combine multiple PDF documents into a single file.
- **Split PDF:** Separate pages from a large PDF document.
- **HTML to PDF:** Convert HTML code or plain text into a PDF file.
- **PDF to Images:** Extract each PDF page as high-resolution JPG images.
- **ID Card Scan to PDF:** Scan Front & Back of ID cards onto a single A4 page.
- **Watermark PDF:** Add custom text overlays across PDF pages.
- **Protect PDF:** Encrypt PDFs with password protection.

### 🖼️ Live Image Resizer & Compressor
- **Live Dimension Resizer:** Resize photos to exact pixels (`1500x1500px`), centimeters, millimeters, or inches with live dimension and KB size preview.
- **Target Size Compressor:** Compress photos to exact target sizes (e.g., **20 KB, 50 KB, 1 MB**) for government, bank, and online application forms.
- **Passport & Visa Crop:** Crop photos to standard **35x45mm** official passport dimensions.
- **Format Converter:** Convert images between JPG, PNG, and WebP instantly.

---

## 🔒 100% Private & Secure
All image and PDF processing runs **entirely inside your browser** using local JavaScript. No files are uploaded to any external server, ensuring complete privacy.
